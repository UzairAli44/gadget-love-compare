# CompareGadgetsHub homepage

## Goal
Build the complete, mobile-first homepage from the supplied brief, with a polished comparison-shopping experience for Pakistani buyers.

## What I’ll build
- Sticky branded header with desktop navigation and an expanding mobile search control.
- High-impact search-first intro with live product suggestions, Pakistan/worldwide mode switch, and quick filters.
- Trust statistics, ten realistic trending products, worldwide savings highlights, categories, brands, budgets, process steps, reporting banner, and footer.
- Product imagery created as lightweight original visual assets, with realistic Pakistani product names and PKR prices.
- Device-aware light/dark themes, accessible keyboard interactions, readable 360px layouts, desktop grids, and restrained motion.

## Interaction details
- Search suggestions filter as visitors type and support keyboard selection.
- Pakistan/worldwide switch updates contextual search and pricing messaging.
- Mobile navigation and search open without crowding the header.
- Product lists scroll horizontally on phones and become grids on larger screens.
- Buttons and filter chips provide clear working feedback without adding accounts or backend features.

## Technical details
- Keep all replaceable content in one typed mock-data module.
- Define the full teal/blue, green-savings, red-premium design system through semantic tokens.
- Use React/TanStack routing, Tailwind utilities, and lightweight CSS animations only.
- Add unique homepage metadata and retain no placeholder content.
- Verify the finished page at desktop and 360px widths, including search, mode switching, navigation, and browser console health.
